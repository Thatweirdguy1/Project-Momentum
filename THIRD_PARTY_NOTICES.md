# Third-party sources and publication boundaries

USDA FoodData Central data: public domain / CC0 1.0, per [USDA's licensing statement](https://fdc.nal.usda.gov/). Source/version/IDs remain in the records. Attribution is supplied in the nutrition documentation.

Exercise metadata and instruction text: Copyright (c) 2026 Hasan Emir Yıldırım; MIT license, reproduced in `data/exercises/upstream-LICENSE`. The accompanying upstream media exception and NOTICE remain intact. No Gym visual image/GIF assets are redistributed or hotlinked by this app.

INDB: locally downloaded from Anuvaad. No explicit dataset redistribution permission was established; workbook and extracted rows are ignored by Git and omitted from releases. Source/methodology links and importer code are public.

JEFIT, Muscle & Strength, ACE, MyFitnessPal, MOTRA, MacroFactor and Calculator.net retain rights in their respective content/media/brands. Public reference facts, links, original summaries and original implementations are supplied; source pages, copied scripts, commercial programs and video files are not published here. Their names indicate research sources, not endorsement or affiliation.

Stitch-generated concepts reference Google Fonts/Material Symbols/Tailwind resources. These references are retained in static concept HTML and require network access; no third-party font binary is bundled. Review production dependency licensing before turning those exports into an application.
