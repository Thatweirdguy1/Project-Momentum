# Changelog

## v0.2.0-diary — 2026-11-16

- Added a persistent, meal-based food diary with original dark Momentum UI, modeled on MyFitnessPal's core food workflows.
- Added portion review, quick add, custom foods, editable recipes with cooked yield, saved meals, copying, edit/delete/undo, recent/frequent/favorites, water/notes and manual goals.
- Added daily/seven-day nutrient reports and a compact USDA micronutrient lookup.
- Added IndexedDB transactions, cross-tab revision protection, offline app/food caching, JSON backup/restore and CSV export.
- Added optional manual Open Food Facts barcode lookup; controlled mapping/UI tests passed, live service probe was unreadable and remains unverified.
- Added model/barcode tests and isolated browser checks, with synthetic desktop/mobile screenshots. User diary data is not included in the repository.

Core food workflows are functional; complete MyFitnessPal feature/catalog parity and native/cloud integration remain unfinished.

## v0.1.0-research — 2026-11-16

- Created a private Google Stitch project and shared dark design system.
- Added six desktop web and four iPhone screen concepts with HTML and screenshots.
- Added sanitized competitor research, public media references, requirement mapping and explicit access limits.
- Reviewed generated copy to remove unsupported claims and distinguish synthetic state from live behavior.
- Kept the source memorandum, raw captures and local investigation state outside Git.
- Added 28 original local calculator categories and a browser workspace with input validation and visible method limits.
- Imported 13,649 USDA foods / 1,019,278 nutrient observations; collected 1,014 INDB recipes locally, with a redistribution hold.
- Imported 1,324 MIT exercise text records in ten languages; collected 904 public exercise references and excluded separately licensed media.
- Added calculator fixtures, browser checks, artifact validation and CI.

This tag identifies research, visual design and functioning local tools, not the complete fitness ecosystem.
